# mapové podklady pro robotour

Mapové podklady jsou odladěny speciálně pro prostředí Stromovky. Jsou založené na datech z OpenStreetMap.

Mapa je uložena offline v robotovi přímo u služby
Při spuštění mise se vytvoří instance mapy ve složce 
`/data/robot/maps-stromovka/<yyyy-mm-dd>/<HH-MM-SS>/`




# requirements:
pip3 install geopandas osmnx networkx matplotlib rtree
